# Fluxo Git

## Estratégia

- `main` deve permanecer utilizável.
- Mudanças são pequenas e focadas.
- Não misturar refatoração ampla com nova funcionalidade sem necessidade.

## Commits

- Mensagens descrevem intenção.
- Não incluir segredos, builds ou arquivos temporários.
- Revisar o diff antes do commit.

## Antes de integrar

- Formatação verificada.
- Análise estática executada.
- Testes relevantes passando.
- Documentação atualizada.
- Alterações de banco versionadas em migrations.
