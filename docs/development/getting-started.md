# Preparação do ambiente

## Requisitos

- Flutter compatível com `pubspec.yaml`.
- Android Studio e Android SDK.
- Emulador ou dispositivo Android.
- Git.
- Acesso aos ambientes de desenvolvimento quando integrações existirem.

## Verificação

```sh
flutter --version
flutter doctor
flutter devices
```

## Execução

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

Credenciais reais não devem ser versionadas.
