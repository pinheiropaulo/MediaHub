# Registros de decisões arquiteturais

ADRs registram decisões estruturais difíceis de alterar. Uma decisão aceita não é reescrita; um novo ADR pode substituí-la preservando o histórico.

## Estados

- Proposto.
- Aceito.
- Substituído.
- Rejeitado.
