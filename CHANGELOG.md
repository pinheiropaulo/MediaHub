# Changelog

Todas as mudanças relevantes do Media Hub serão registradas neste arquivo.

O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/). O projeto adotará versionamento semântico quando iniciar lançamentos.

## [Unreleased]

### Added

- Projeto Flutter inicial.
- Tema dark com destaque amber.
- Protótipos de Login e Início.
- Riverpod e `go_router`.
- Documentação modular de produto, arquitetura, backend, design e desenvolvimento.

### Changed

- Escopo do MVP reduzido para filmes, séries e animes.
- Nome do produto padronizado como Media Hub.
- Implementação consolidada para mobile, sem pares de layouts Web/mobile.

### Removed

- Layouts Web duplicados do código do MVP.
- Tela Web provisória de detalhes.
